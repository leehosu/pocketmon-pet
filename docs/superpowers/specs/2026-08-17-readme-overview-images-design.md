# README Overview 이미지 디자인

## 목표

`pocketmon-pet`의 핵심 경험을 README 첫 화면에서 즉시 전달하는 16:9 이미지 두 종을 제작하고, 사용자 확인 후 선택본을 README에 연결한다.

## 산출물

- `docs/assets/readme/overview-product.png`: 실제 제품 경험 중심 히어로
- `docs/assets/readme/overview-illustration.png`: 감성 픽셀아트 중심 히어로
- 공통 크기: 1,600×900 px

## 시안 A — 제품 히어로

- 실제 Electron 펫 화면을 주인공으로 배치한다.
- 어두운 코딩 데스크톱을 배경으로 사용하되 코드 내용은 흐리게 처리한다.
- 펫, 레벨·XP UI, always-on-top 특성이 한눈에 보이도록 구성한다.
- 그래파이트·네이비 배경에 골드 포인트를 사용한다.
- 가짜 기능이나 실제 앱에 없는 복잡한 UI는 추가하지 않는다.

## 시안 B — 감성 일러스트

- 고급 8비트·16비트 픽셀아트로 코딩, 성장, 진화의 흐름을 한 장면에 담는다.
- 책상 위 코딩 환경과 작은 동료의 유대감을 중심으로 연출한다.
- 빛 입자와 세 단계 실루엣으로 진화를 암시하되 게임 포스터처럼 과장하지 않는다.
- 제품 히어로와 동일한 그래파이트·네이비·골드 팔레트를 사용한다.

## 공통 제약

- 워터마크, 저해상도 픽셀, 왜곡된 텍스트, 과도한 네온을 금지한다.
- 화면 가장자리 8%를 안전 여백으로 유지한다.
- README 다크·라이트 테마 모두에서 경계가 분명해야 한다.
- 이미지 내부 문구는 최소화하며 필요 시 `POCKETMON PET`만 정확히 사용한다.
- 제3자 로고와 상표 표시는 추가하지 않는다.

## 검수

- 두 이미지를 직접 확인해 구도, 텍스트, 실제 기능 일치 여부를 점검한다.
- 사용자에게 두 시안을 함께 제시하고 선택 또는 수정 의견을 받는다.
- 선택 전에는 README에 최종 이미지를 고정하지 않는다.
